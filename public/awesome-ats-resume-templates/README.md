## 📄 Open Source JSON Resume Schema Example

```json
{
  "basics": {
    "name": "Alex Morgan",
    "label": "Software Engineer",
    "email": "alex.morgan@email.com",
    "phone": "(555) 019-2834",
    "url": "https://alexmorgan.dev",
    "summary": "Results-driven Software Engineer with 5+ years of experience designing scalable microservices.",
    "location": {
      "city": "San Francisco",
      "region": "CA",
      "countryCode": "US"
    }
  },
  "skills": [
    {
      "name": "Programming",
      "keywords": ["TypeScript", "Python", "React", "Node.js", "PostgreSQL", "AWS", "Docker"]
    }
  ]
}
```
